FUNDAMENTE
Apache Spark: modelul mental
Un program descrie transformările; Spark decide cum să le execute.
DRIVER
Coordonează
Construiește planul de execuție, pornește task-uri și colectează rezultate mici.
EXECUTORS
Procesează
Aplică transformări asupra partițiilor și execută task-uri în paralel.
STORAGE
Stochează
Citește și scrie CSV, JSON, Parquet sau alte surse de date.

FUNDAMENTE
Transformations vs. actions
Spark construiește un plan și îl execută numai când este necesar.
LAZY · TRANSFORMATION
Nu rulează imediat
select() · filter() · withColumn() · join() · groupBy()
EXECUTION · ACTION
Declanșează calculul
show() · count() · collect() · write()
Atenție: collect() mută rezultatele pe driver. Nu îl folosi pentru milioane de rânduri.

from pyspark.sql import functions as F
result = (df
.withColumn("customer_id", F.col("id") % 10000)
.filter(F.col("customer_id") < 5000)

)

MODEL

CONTRACT
Ce definește StructField?
StructField("nume", tip, nullable) definește o coloană: numele, tipul valorilor și dacă sunt permise NULL. StructType grupează aceste câmpuri într-o schemă.

from pyspark.sql import functions as F
tx = (spark.range(1_000_000)
.withColumnRenamed("id", "transaction_id")
.withColumn("customer_id",
(F.rand(42) * 10_000).cast("int"))
.withColumn("amount",
F.round(F.rand(43) * 500 + 1, 2))
)
SEED
Reproductibilitate
Un seed fix ajută la obținerea acelorași rezultate într-un context de execuție stabil; nu înlocuiește versionarea.
GENERARE
Creăm categorii cu proporții diferite.
Exemplu: 60% electronică, 30% îmbrăcăminte, 10% cărți.
PYSPARK
u = F.rand(seed=44)
tx = tx.withColumn("category",
F.when(u < 0.60, "electronics")
.when(u < 0.90, "clothing")
.otherwise("books")
)
tx.groupBy("category").count().show()

GENERARE
Injectăm valori lipsă într-un câmp.
Important: păstrăm un ground truth al modificărilor.
PYSPARK
tx = tx.withColumn("amount",
F.when(F.rand(49) < 0.02,
F.lit(None).cast("double"))
.otherwise(F.col("amount"))
)
tx.select(
F.avg(F.col("amount").isNull().cast("int"))
.alias("null_rate")
).show()
OBIECTIV
~2% null-uri
Rata observată este aproximativă. Documentăm dacă lipsurile sunt aleatoare sau dependente de grup.
ENRICHMENT
Joins: integrăm mai multe surse.

PYSPARK
customers = (spark.range(10_000)
.withColumnRenamed("id", "customer_id")
.withColumn("segment",

)
enriched = tx.join(customers, "customer_id", "left")

PERFORMANȚĂ
Capcane de performanță
PySpark este scalabil când scriem expresii compatibile cu motorul său.
ANTI-PATTERN
collect() masiv
Aduce toate datele pe driver. Folosește show(), limit() sau agregări.
ANTI-PATTERN
UDF în Python
User Defined Function: funcție personalizată aplicată datelor din coloane.
ANTI-PATTERN
repartition() la întâmplare
Partițiile prea multe sau prea puține pot degrada performanța.
De ce contează? UDF-urile Python pot adăuga cost de serializare și execuție între Spark/JVM și Python. Preferă funcțiile native (ex.: upper, when, concat) când sunt suficiente.
