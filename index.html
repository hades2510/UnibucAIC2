FUNDAMENTE · SPARK

Ce face Apache Spark?

Spark este un motor de procesare a datelor: citește, transformă, combină și analizează volume mari de informații.

01 · CITIRE

Încarcă date

CSV, JSON, Parquet, baze de date și alte surse.

02 · PROCESARE

03 · REZULTAT

Produce date utile

Spark execută operațiile pe un singur calculator sau pe mai multe mașini dintr-un cluster.

FUNDAMENTE · SPARK

Spark vs. PySpark

Apache Spark este motorul de execuție. PySpark este interfața Python prin care descriem ce vrem să facă.

PYTHONCod PySparkDataFrames, funcții și SQL
scrise din Python
→
SPARKMotorul SparkPlanifică și optimizează
operațiile
→
EXECUȚIECPU + memorieExecută task-uri pe
partițiile de date

PySpark nu înseamnă că fiecare rând este procesat într-o buclă Python: expresiile DataFrame rulează în motorul Spark.

FUNDAMENTE · SPARK

Cum procesează Spark datele în paralel?

Datele sunt împărțite în partiții. Spark distribuie task-uri care pot rula simultan.

EXEMPLU · 1 MILION DE RÂNDURI

Un DataFrame,
mai multe partiții

Spark poate procesa fiecare partiție independent pentru operații precum selectarea sau filtrarea.

Partiția 1Task 1
Partiția 2Task 2
Partiția 3Task 3
Partiția 4Task 4

Nu toate operațiile sunt ieftine: un join sau groupBy poate necesita transfer de date între partiții (shuffle).

FUNDAMENTE
Apache Spark: modelul mental
Un program descrie transformările; Spark decide cum să le execute.
DRIVER
Coordonează
Construiește planul de execuție, pornește task-uri și colectează rezultate mici.
EXECUTORS

Aplică transformări asupra partițiilor și execută task-uri în paralel.
STORAGE
Stochează
Citește și scrie CSV, JSON, Parquet sau alte surse de date.

PERFORMANȚĂ
Capcane de performanță
PySpark este scalabil când scriem expresii compatibile cu motorul său.
ANTI-PATTERN
collect() masiv
Aduce toate datele pe driver. Folosește show(), limit() sau agregări.
ANTI-PATTERN
UDF în Python
User Defined Function: funcție personalizată aplicată datelor din coloane.
ANTI-PATTERN
repartition() la întâmplare
Partițiile prea multe sau prea puține pot degrada performanța.
De ce contează? UDF-urile Python pot adăuga cost de serializare și execuție între Spark/JVM și Python. Preferă funcțiile native (ex.: upper, when, concat) când sunt suficiente.
